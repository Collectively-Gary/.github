# GaryOS Brand Kit

Shared visual identity for GaryOS and everything built on it: the blue Gary mascot, often shown holding a small yellow chick.

| Folder | Contents |
|---|---|
| `logo/` | `garyos-logo-circle.jpg`: primary GARY os wordmark with mascots, on a black circle |
| `mascot/` | Mascot poses (`mascot-NN.webp`), renders, and a wide banner (`mascot-banner-with-chick.png`) |
| `scenes/` | Illustrated scenes: Gary mascots on a grassy hillside, TV-on-hill, background tests |
| `motion/` | `gary-motion-graphic.mp4`: short animated clip |
| `audio/` | `gary-audio-1.mp3`: audio sting |

## Palette (sampled from the art)

- Gary blue (body): approx `#1E4FE0`
- Visor white: `#F2F4F8`
- Accent orange (ear pieces): approx `#F5A623`
- Chick yellow: approx `#FFD54A`
- Wordmark light blue: approx `#BCD3FB`

Hex values are eyeballed approximations, not official specs.

## Usage

- Keep the mascot's proportions and colours unchanged. Don't recolour Gary.
- The chick is Gary's companion. Show it cared for, never harmed.
- Raw source footage (iPhone `.MOV`, ~644MB) is kept off git and lives with the original download.
